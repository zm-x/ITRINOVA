# ItriNova Landing Page

A minimalist, sketch-like landing page for ItriNova - the exclusive professional networking platform for the commercial Low Earth Orbit workforce.

## Features

- **Dark/Light Theme Toggle**: Seamless switching between dark and light modes
- **Responsive Design**: Optimized for desktop and mobile devices
- **Sketch-like Earth Illustration**: Rotated earth.png with blur shadow effects
- **Dynamic Typography**: Alternating blue and white letters in the main title
- **Professional Focus**: Highlighting LEO industry specialization

## Technologies Used

- React 18
- Tailwind CSS 3
- Pure CSS animations and effects

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Design Features

- **Minimalist Layout**: Clean, professional design focused on content
- **Earth Illustration**: Uses earth.png as a central visual element with 10-degree rotation and blur shadow
- **Theme Adaptability**: All elements dynamically adjust colors for optimal visibility
- **Professional Branding**: Logo placement and sign-in/login functionality
- **LEO Industry Focus**: Content specifically tailored for Low Earth Orbit professionals

## About ItriNova

ItriNova is a specialized professional networking platform designed exclusively for the commercial Low Earth Orbit workforce. Unlike general platforms, ItriNova focuses on:

- Verified profiles for LEO industry professionals
- NASA-backed certifications and training
- ITAR compliance and regulatory awareness
- Specialized job matching for orbital careers
- Global networking for space industry growth

## Build for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.
